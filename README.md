# Experiment 4 – Utilize the Assets and Media

**Course:** 24CS2016 – Building Applications using Flutter  
**Name:** Jomi W  
**Register No.:** URK23CS1299

## Aim

To add and display image, audio and video assets in a Flutter application.

## Description

This experiment demonstrates how to configure and use media assets in a Flutter application. An image is added through the assets directory and registered in pubspec.yaml for use in the app. Image.asset and GridView.count are used to display individual images and build a simple image gallery.

## Source files

- `pubspec.yaml`
- `lib/main.dart`

## How to run

The repository contains the Dart source and `pubspec.yaml`. Generate the platform folders once, then run:

```bash
flutter create .
flutter pub get
flutter run
```

## Result

A Flutter media application was created and configured to use local image assets. The asset directory was added and registered correctly in pubspec.yaml. The configured image was displayed using Image.asset and arranged in a gallery using GridView.count. The application successfully loaded and displayed the configured media assets.
